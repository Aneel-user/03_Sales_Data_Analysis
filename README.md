
# Sales Data Analysis Project

## Project Overview
This project analyzes sales data using Python, SQL, Excel, and Power BI to identify business trends, top-performing products, customer behavior, and regional sales performance.

## Tools and Technologies
- Python — data analysis and visualization
- Pandas — data manipulation
- Matplotlib — charts and graphs
- SQL Server — querying and business analysis
- Microsoft Excel — PivotTables and KPI calculations
- Power BI — interactive dashboards

## Dataset
The dataset contains 100 sales records with information about:
- Order ID and order date
- Customer name
- Product and category
- Quantity and unit price
- Region and salesperson
- Payment method
- Sales amount

## Business Questions
1. What are the total sales and total orders?
2. Which products generate the most revenue?
3. Which region performs best?
4. Who are the top customers and salespeople?
5. Which payment methods are most popular?
6. How do sales change month by month?

## Key Findings
- Total Sales: ₹5,973,500
- Total Orders: 100
- Total Quantity Sold: 319
- Average Order Value: ₹59,735
- Total Customers: 10
- Total Products: 6
- Best-Selling Product: Laptop
- Best-Performing Region: West
- Top Salesperson: Ravi
- Top Customer: Arjun
